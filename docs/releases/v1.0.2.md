# Shapey 5-Band EQ v1.0.2

## What's new
- **Desktop VST3 for MPC Desktop and DAWs:** `Shapey-5-Band-EQ-1.0.2-macos-vst3.zip` (one file for Apple Silicon and Intel Macs, with the same touchscreen skin in the plugin window) and `Shapey-5-Band-EQ-1.0.2-windows-vst3.zip` (64-bit; the host shows the parameters, no skin window yet).
- **Device projects open on the computer:** the VST3 has the VST2's official replacement ID, so a project saved on the MPC with this plugin loads it in MPC Desktop (controller mode) instead of showing a missing plugin, with the same sound and settings. A project saved on the desktop opens on the MPC the same way.

## Fixed
- No device-side changes besides the rebuilt wrapper; the MPC plugin behaves as before.
